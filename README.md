## Overview

This project is part of my personal effort to build portfolios using different frameworks.  
This version is built with React, styled using Tailwind CSS, and animated with motion.dev.

## Features

- Fully animated with motion.dev
- Section-based navigation via navbar
- Dark mode toggle

## Tech Stack

This portfolio is built using:
- Vite
- React
- TypeScript
- Tailwind CSS
- motion.dev
- React Icons
